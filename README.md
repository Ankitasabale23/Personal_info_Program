# Simple Calculator

## Description

This is a simple Python calculator program that accepts two numbers and performs basic arithmetic operations.

## Objective

To practice arithmetic operators, user input, and basic Python programming logic.

## Operations

The program performs:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)

## Division by Zero

The program checks if the second number is zero before performing division and modulus operations.

## Tools Used

- Python
- VS Code

## Input

The program accepts two numbers from the user.

## Output

The program displays the results of addition, subtraction, multiplication, division, and modulus.

## How to Run

Run the calculator.py file using Python and enter two numbers when prompted.
